# host/ — 宿主侧(你的 Mac / 服务器)

设备是 MCP 服务端,**这一侧是客户端**。跑在能到达设备的机器上(同网段直连是主路径)。

## 职责

1. **发现设备**:mDNS 扫 `_ioagent._tcp.local` → 拿到设备地址与型号,不用手填 IP。
2. **配对**:首次连接出示一次性配对码 → 设备校验后换回长期 PSK(存本地)。
3. **调用**:直接用标准 MCP 客户端连设备的 MCP server,调用
   - `status` — 设备身份与状态(含 `watcher.running`)
   - `ls` / `read` — 列共享盘 / 按 8.3 文件名读
   - `capture` — 取最新一帧(MCP 原生 image 块)
   - `input` — 动作序列(按键/鼠标 + 内嵌延时)一次下发,设备本地按序执行(<10ms/步)
   - `update` — 把内容写进 flash 槽位(下次开机生效)
4. **本地缓存(可选)**:把抓到的帧落盘,便于回看与对比。

## 目录

| 目录 | 内容 |
|---|---|
| `client/` | MCP 客户端 + 联调 CLI(发现 / 配对 / 取帧 / 注入) |
| `adapter/` | **选做**:设备端做不动全量 MCP 时的兜底——设备只提供极简 HTTP API,这一层做协议转换 |

## 前提

- host 必须**能到达设备**(同网段直连;跨网需要中继,本期不做)。
- 设备与 host 持同一把 PSK(或先用配对码换)。
- 目标机上**不需要装任何东西**——驻守脚本藏在设备的虚拟 U 盘里,由设备用 HID 拉起。

## 国际化

MCP 工具描述、CLI 输出、面向用户的报错文案一律走 zh-Hans + en 双语资源,禁止硬编码;
协议层字段与文件名保持 ASCII。

## 注意

不要在本目录保存设备 PSK 等凭据的明文副本;按需从钥匙串/环境变量取。
